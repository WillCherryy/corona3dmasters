### A13. What the H-CO2 data files contain (checked 6 Nov 2026 on the 5 eV file, `E5.00-DCS.txt`)
- Each source file holds 27 blocks of 1,800 rows (angle 0.1 to 180 degrees, differential cross section in Angstrom^2 per steradian). The header line of each block gives the initial and final CO2 rotational state: `LEV(I),J(I)` = 1, 0 (CO2 starts in j = 0 in every block) and `LEV(F),J(F)` = the final state.
- Block 1 (`LEV(F),J(F) = 1 0`, final j' = 0): ELASTIC. CO2 stays in its starting rotational state; no energy goes into rotation.
- Blocks 2 to 27 (final j' = 2, 4, ..., 52): ROTATIONALLY INELASTIC. The H atom spins CO2 up and loses energy; only even j' occur (symmetry of CO2). These are generally deflected through larger angles.
- User's `test` branch files = block 1 only, converted Angstrom^2 -> cm^2 (x 1e-16). Verified row by row against the source: 1,800 rows, identical angles, maximum relative difference 2e-16.
- Integrated cross sections at 5 eV: elastic (j' = 0) 2.21e-15 cm^2; j' = 2: 5.3e-16; j' = 10: 1.2e-16; j' = 20: 7.8e-17; j' = 52: 1.5e-17; sum over all 27 blocks 4.58e-15. Elastic is therefore about 48% of all collisions at 5 eV.
- Angular character (own trapezoid integration of the tables; mean of 1 - cos(theta), proportional to momentum transfer): O-H (Zhang) 0.33 at 1 eV and 0.20 at 5 eV; H-CO2 elastic only 0.011 and 0.006; H-CO2 total (all blocks) 0.23 and 0.09. The elastic-only scattering is almost entirely straight-ahead, so energy lost per collision with CO2 falls from about 1.5% (O-H angles with CO2 mass) to under 0.1% at 1 eV.
- DECISION (user, 6 Nov 2026): run elastic-only H-CO2 now, because the existing O-H, N2 and CO data are also elastic (Zhang et al. 2009). Integrating the inelastic channels (sum over blocks, the "total" variant, files already available on branch `claude/exciting-keller-mu4f4t`) is a planned next step after the other results are verified. In the thesis, describe the result as the elastic-channel approximation and give the 48% figure; note that the elastic-only escape rate is expected to be an upper bound for CO2.

### A38. Check that the partner-selection fix does not double count the cross sections (12 Nov 2026)
- QUESTION (user): does weighting the partner choice by sigma_s n_s count the cross sections twice? ANSWER: no. In `check_collision` the probability that a collision happens at all is 1 - exp(-tau), tau = sum_s v dt sigma_s n_s, unchanged by the fix; the fix changes only the split among species given that a collision happened, P(s | collision) = sigma_s n_s / sum(sigma n) = tau_s / tau. The probability of a collision with species s is therefore (1 - exp(-tau)) tau_s / tau, i.e. sigma appears once in the total and, normalised, once in the split. Both use the same `total_sig` array computed earlier in the same call.
- TOY MONTE CARLO (own check, 4 million steps, O with sigma = 4.6e-15 and CO2 with sigma = 2.6e-15 cm^2, densities 1.0e11 and 6.0e10 cm^-3, v dt tau = 1.23): total collision probability 0.7084 for both the old and the new selection (expected 1 - exp(-tau) = 0.7083); CO2/O collision ratio 0.600 with the old density-only split (= the density ratio) and 0.339 with the new split (= the sigma n ratio 0.339, the correct value). So the fix leaves the total unchanged and corrects the split.

### A46. The user's formulation of the collision logic (15 Nov 2026) - recorded as the user's own reasoning for the write-up
- USER'S REALISATION (their words, lightly edited): the probability of a collision is decoupled from the choice of gas in the code. The absolute probability of a collision is set by the cross sections and densities together. Given that a collision has occurred, the question of which species was hit is a conditional probability; the old code made this choice by density alone, and the code now includes the size of each cross section in this choice. The user asked whether this is correct statistics.
- CONFIRMED, with one correction to the wording: before the change the gases were chosen in proportion to their DENSITIES, not 25% each (equal shares only when the densities are equal; at low altitude CO2 is about 95% of the molecules).
- THE STRUCTURE: (1) P(collision) = 1 - exp(-tau), tau = v dt sum_s(sigma_s n_s); (2) P(species s | collision) = sigma_s n_s / sum(sigma n) (new) against n_s / sum(n) (old); (3) P(collision with s) = P(collision) x P(s | collision), which for small tau equals sigma_s n_s v dt, the physical rate with one cross section per species. This is the standard result for competing independent events (the split of the total rate in proportion to the individual rates). Both stages use the same cross-section values within a step (`total_sig` computed once per step).
- EVIDENCE: toy Monte Carlo (A38), equal-cross-section bit-identical test (A39, A41), instrumented expected-versus-actual collision counts per species in the real code (A45): fixed code within about 1% for every species; old code about 36% too few collisions for O, N2 and CO with the elastic H-CO2 data, with the total correct.
- FOR THE WRITE-UP: the old choice gave every gas the density-weighted average cross section instead of its own; the correction does not change the total collision frequency, the cross-section data or the scattering of any single collision, but it changes the mix of collision partners, and each partner has its own mass and angular distribution, so it changes the results when the cross sections differ (about 20% lower elastic loss rate in a 400-particle test).
